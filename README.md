# Global Analysis

This repo has my Google Earth Engine work for the Global Scale Analysis module in MB5370.

## Deep Ocean Ecosystems

I used ETOPO1 bathymetry to map deep ocean ecosystem types using depth and seafloor slope.

## Allen Coral Atlas

I used the Allen Coral Atlas to compare coral and algae habitat within 800 metres of different research stations.

## Scripts

`deep_ocean_ecosystems.js`  
Deep ocean ecosystem mapping.

`allen_coral_atlas.js`  
Coral and algae area around research stations.

## Data

Deep ocean data came from NOAA ETOPO1.

Coral habitat data came from the Allen Coral Atlas.

Hydrothermal vent locations came from the InterRidge Global Database of Active Submarine Hydrothermal Vent Fields. I downloaded the data and uploaded it into Google Earth Engine as a vector layer.
